# Infectious Quanta Single-Hit Model

This repository contains the computational code supporting the manuscript:

**Biological decomposition of infectious quanta using a calibrated single-hit model**

The model represents the successive pathway

`N → M → R → X → L → D → Z`

and links this biological and exposure pathway to the derived inhaled quantum dose, `Q_inh`.

## Repository contents

### `notebooks/01_Exposure_Model_and_Inhaled_Aerosol_Distribution.ipynb`

Reproduces the source-to-recipient aerosol exposure calculation used in the manuscript. It derives:

- the expected number of inhaled aerosols, `mu`;
- the inhaled aerosol-radius distribution, `f_R(r)`.

Using the baseline exposure settings, the calculation gives `mu ≈ 350.76`, reported approximately as `mu = 350` in the manuscript simulation settings.

### `notebooks/02_Baseline_Calibration_and_Recovery.ipynb`

Reproduces the baseline calibration and in vivo recovery analysis.

The notebook:

- generates the calibration and in vivo simulation outcomes;
- fits the one-parameter Stan model for the identifiable product `phi = n q`;
- determines `q` from the calibration setting with known `n_cal`;
- recovers `n_vivo` from the independently estimated in vivo product;
- reconstructs the corresponding inhaled quantum dose `Q_inh`.

The fixed random seeds reproduce the baseline results reported in the manuscript.

### `notebooks/03_Radius_Distribution_Robustness.ipynb`

Reproduces the analysis in which the calibration and in vivo aerosol-radius distributions differ.

The calibration emitted median radius is `0.180 micrometres`, whereas the in vivo emitted median radius remains `0.139 micrometres`; the geometric standard deviation is `1.64` in both settings. The correct radius distribution is used in each corresponding model fit.

## Software requirements

The notebooks use Python 3 and the following Python packages:

- `numpy`
- `pandas`
- `arviz`
- `cmdstanpy`

Notebooks 02 and 03 install `cmdstanpy` and `arviz` if needed and use **CmdStan 2.40.0**. A C++ toolchain compatible with CmdStan is therefore required.

No external data files are required. The calibration and in vivo outcomes used in the manuscript are generated within the notebooks from fixed simulation settings and random seeds.

## Running the analysis

The recommended order is:

1. `01_Exposure_Model_and_Inhaled_Aerosol_Distribution.ipynb`
2. `02_Baseline_Calibration_and_Recovery.ipynb`
3. `03_Radius_Distribution_Robustness.ipynb`

Notebook 01 establishes the exposure calculation underlying the baseline expected inhaled aerosol count. Notebooks 02 and 03 are computationally self-contained for their respective calibration and recovery analyses.

The first execution of Notebooks 02 or 03 may take longer because CmdStan may need to be installed and the Stan model compiled.

## Generated files

Stan sampling files are written to repository-local subdirectories under:

`outputs/`

The `outputs/` directory is excluded from version control through `.gitignore` because these files can be regenerated by running the notebooks.

## Reproducibility

The simulation and posterior sampling steps use fixed random seeds. Small differences in low-level numerical output may occur across software versions or computing environments, but the notebooks specify the CmdStan version used for the reported analysis.

## Data

This study uses simulation rather than participant-level or clinical data. No external individual-level dataset is required to reproduce the computational analyses in this repository.
